# Qiao Li Portfolio Analysis

This document details the layout, typography, and styling details of Qiao Li's interaction and product design portfolio ([qiaooli.com/work](https://qiaooli.com/work)).

---

## 🎨 Visual Style & Theme
* **Color Palette:** Sleek, high-contrast typography-focused light theme.
  * **Background:** Ivory/White (`#ffffff` or soft cream)
  * **Text/Accent:** Charcoal Black
* **Core Aesthetics:** Immersive interaction design focus. It utilizes sparse borders, bold large type headers, and spacing systems that favor white space to create visual breathing room.

---

## 🅰️ Typography & Character Splitting
* **Split character nodes:** 
  * The site structure splits text characters into individual `<span>` tags. For example, `"I am Qiao, a designer..."` is represented as separate child nodes for every single character.
  * This is a signature web animation technique (often implemented with GSAP SplitText or CSS variables) that allows animating letter entries dynamically, making headings feel like they are typing, fading, or scattering in as the page loads.

---

## 📐 Layout & Structure
* **Project Case Grid:**
  * Uses a clean list layout detailing case studies: **Grantx** (AI funder database), **Ounce by Ocean Spray** (branding/packaging), **A Distant Slumber** (Unreal Engine story world), and **DELETE** (motion installation).
  * Minimal styling with clean border lines separating projects.
