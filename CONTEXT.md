# Domain Glossary

This document serves as the single source of truth for the terminology and business concepts used in the Maniteja Portfolio website.

---

### Maniteja
The personal brand name of the founder, signifying a hybrid creator who specializes in both design and automation.

### AI Agency
The business model and service entity through which Maniteja delivers AI-driven solutions, web development, and digital optimization.

### Workflow Creation
The design, structuring, and execution of automated pipelines where AI agents, APIs, and logic gates coordinate to perform business tasks without manual intervention.

### AI Automation
The implementation of artificial intelligence models (such as LLMs, vision models, and classifiers) to automate repetitive cognitive tasks.

### Website Creation
The end-to-end process of designing, developing, and deploying high-performance, responsive web applications.

### UI/UX Designing
The craft of creating user interfaces (UI) and user experiences (UX) that are visually stunning, intuitive, and performant.

### SEO (Search Engine Optimization)
The practice of structuring web content and metadata to rank highly on traditional algorithmic search engines (e.g., Google, Bing).

### GEO (Generative Engine Optimization)
The modern practice of optimizing content structure, semantic markup, and knowledge graph relations so that it is accurately retrieved, cited, and recommended by Generative AI search systems (e.g., Gemini, ChatGPT Search, Perplexity).

### n8n Workflow
A custom automated pipeline designed and executed within the n8n automation platform, consisting of triggers (such as webhooks or schedules), logic nodes (conditional routing, JS code), and action nodes (syncing with CRMs, triggering LLMs).

### Interactive Workflow Gallery
The portfolio section dedicated to showcasing Maniteja's custom n8n automations directly on the page, replacing traditional static case studies.

### Dashboard View (SaaS Console Layout)
A design layout for the workflow gallery resembling a software application dashboard. It features a sidebar menu listing the available automations, which updates a central visual workspace and telemetry panel when clicked.

### Expandable Bento Cards Layout
A design layout for the workflow gallery where each automation is represented by a separate bento-grid card that can be clicked to expand or open an overlay panel displaying full flow details.

### SEO & GEO Simulation Panels
A side-by-side visual interface demonstrating the difference between traditional search rankings (Google Search Mockup) and AI chat citations (AI Chat Mockup) by auto-animating search queries and generated answers.
